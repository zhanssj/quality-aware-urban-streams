# Quality-Aware Urban Streams: пакет для запуска Codex

> Это описание исходного starter-пакета от 2026-11-02. Текущее состояние реализации и команды
> находятся в корневом `README.md`, `STATUS.md` и `handoffs/T01.md`.

Это обновлённый план, инструкции и задания для coding agent, а не готовая исследовательская программа.
Дата подготовки: 2 ноября 2026 года. Прикладной код, обучение моделей и запуск экспериментов в рамках подготовки этого пакета не выполнялись.

## Как начать

1. Создай отдельный приватный Git-репозиторий либо используй выбранный исследовательский репозиторий. Предлагаемое имя: `quality-aware-urban-streams`. Этот пакет не создаёт репозиторий на GitHub/GitLab.
2. Скопируй содержимое этой папки в корень репозитория. При наличии файлов с такими же именами сначала сравни их; не перезаписывай существующую работу автоматически.
3. Исходные HDF5 оставь на своём компьютере вне Git. Укажи локальный путь агенту либо через `AQ_DATA_ROOT`; не загружай файлы заново.
4. Открой этот корень проекта в локальном Codex. Передай текст из `prompts/START_CODEX.txt`.
5. Codex реализует только T01, запускает тесты и оставляет отчёт `handoffs/T01.md`. Остальные задачи пока не выполняет.
6. После отправки изменений в согласованный remote дай ChatGPT репозиторий, ветку/PR и commit для ревью. До отправки в remote локальные изменения здесь не видны.

Рекомендуемый маршрут для этого проекта: локальный Codex + GitHub + ревью в текущем ChatGPT.
В текущем диалоге подключение GitHub к аккаунту `zhanssj` проверено, но исследовательский репозиторий ещё не выбран. Разрешение доступа к конкретному новому репозиторию проверяется отдельно после его создания.

## Что читать

- `AGENTS.md`: постоянные правила агента.
- `PROJECT.md`: цель, рамки и текущая точка проекта.
- `IMPLEMENTATION_PLAN.md`: последовательность задач и условия приёмки.
- `docs/EXPERIMENT_PROTOCOL.md`: научный контракт, предотвращающий утечку данных.
- `docs/ARCHITECTURE.md`: модули, границы данных, CLI-контракт.
- `docs/COLLABORATION.md`: совместная работа ChatGPT, Codex и пользователя.
- `tasks/`: отдельные задания с тестами и ограничениями.
- `templates/`: отчёт реализации и независимое ревью.
- `context/previous_audit_review_ru.md`: существующий разбор, приложенный без нового аудита.
- `manifests/cohort_candidates_669.csv`: существующая тренировочная диагностическая группа, не окончательная репрезентативная выборка.
- `STATUS.md`: состояние работы. Пока все задачи реализации TODO.

## Важные ограничения

Полные аудиты завершены. Новый скан всех годов не является задачей T01. Нужны только проверки контракта входа и небольшой smoke-test.
Данные 2025 года уже просмотрены в описательных аудитах; не называем их полностью нетронутым/слепым тестом. При этом никакую модель на них не настраиваем.
Семантика часовых агрегатов, физические единицы и происхождение релиза остаются ограничениями публикационных выводов, а не поводом останавливать создание прототипа.

## Что в пакет не входит

Исходные HDF5, модель, реальные прогнозы, измерения производительности, работающий CI или backend.
Примеры будущих команд в документах являются целевым интерфейсом, который должен реализовать Codex.
Внешние сообщения, GitHub issues/PR и remote commits при подготовке пакета не создавались.
