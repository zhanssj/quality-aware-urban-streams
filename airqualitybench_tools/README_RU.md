# Загрузка и первичная проверка AirQualityBench

## Статус этого комплекта

Это инструменты, а не готовый отчёт о реальном датасете. В текущем сеансе скачать файлы AirQualityBench в рабочую среду не удалось из-за сетевого доступа. Численные результаты для реальных измерений не получены. Проверены страницы источника и документация; локально прошли 4 теста кода аудита на небольшом искусственном HDF5. Сетевой загрузчик здесь не был успешно выполнен.

Самих данных в этом ZIP нет. Отчёт появится только после запуска на скачанных .h5.

## Источники

- Датасет: https://huggingface.co/datasets/xuxing123/AirQualityBench
- Список файлов: https://huggingface.co/datasets/xuxing123/AirQualityBench/tree/main
- Зафиксированная версия: https://huggingface.co/datasets/xuxing123/AirQualityBench/tree/bbdcdd257bc7aed69598d423ca034d03f7ce015e
- Официальная инструкция загрузки: https://huggingface.co/docs/huggingface_hub/en/guides/download
- Чтение HDF5: https://docs.h5py.org/en/stable/high/dataset.html

В наборе опубликованы aq_compact_2021.h5 ... aq_compact_2025.h5. По странице репозитория их размеры примерно 186, 180, 278, 318 и 325 МБ. Нужные пять HDF5 вместе с небольшими метаданными занимают около 1,3 ГБ; оставьте дополнительное место для кеша и результатов. Файл графа adj_mx_10.pkl для этой проверки не нужен и не скачивается.

Скрипт фиксирует commit bbdcdd257bc7aed69598d423ca034d03f7ce015e, чтобы все файлы происходили из одной версии. Для другого commit задайте --revision и новую папку --out. При значении main загрузчик сначала разрешит его в конкретный commit.

## Windows PowerShell

Распакуйте комплект и откройте терминал в папке со скриптами. Нужен Python 3.10 или новее.

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Проверить загрузку и аудит одного обучающего года:

```powershell
.\.venv\Scripts\python.exe download_data.py --years 2021
.\.venv\Scripts\python.exe audit_data.py --years 2021
```

Скачать все пять лет и проверить их:

```powershell
.\.venv\Scripts\python.exe download_data.py
.\.venv\Scripts\python.exe audit_data.py
```

Уже скачанные файлы используются повторно библиотекой Hugging Face. При сетевой ошибке устраните проблему и повторите ту же команду. Активировать virtualenv не требуется, поэтому менять PowerShell ExecutionPolicy не нужно.

## Вариант без скрипта загрузки

Можно скачать файлы через браузер: откройте файл на вкладке Files and versions и нажмите Download. Сохраните aq_compact_YYYY.h5 и selected_nodes_metadata.csv в папку data, затем запустите audit_data.py. В таком случае download_manifest.json не будет; аудит посчитает локальные SHA256, но не сможет сравнить их с сохранённым манифестом загрузки.

При использовании официальной CLI пример для одного года:

```bash
hf download xuxing123/AirQualityBench aq_compact_2021.h5 selected_nodes_metadata.csv --repo-type dataset --revision bbdcdd257bc7aed69598d423ca034d03f7ce015e --local-dir data
```

Читать содержимое нужно через h5py. По документации авторов стандартный load_dataset для этой структуры HDF5 не подходит: внутренние массивы имеют разные длины.

## Что делает аудит

- Открывает каждый указанный HDF5 только на чтение; считывает значения и маски блоками по времени, а не весь набор в память.
- Проверяет наличие values, masks, station_ids, params, совместимость форм, дубликаты идентификаторов, порядок станций и параметров между годами.
- Считает покрытие по mask == 1 и конечному значению, ошибки масок, NaN/Inf под маской наблюдения, отрицательные и нулевые наблюдаемые значения.
- Проверяет диапазоны координат и соответствие идентификаторов метаданным, но не выполняет геокодирование или подтверждение местоположения.
- Для PM2.5 сохраняет статистику по каждой станции и году, максимальные разрывы, первые/последние доступные индексы, начальные/конечные отсутствующие интервалы и разрывы между доступными измерениями.
- Сохраняет SHA256, свойства HDF5, предупреждения и версии библиотек.

Понятие usable в отчёте означает только mask == 1 и конечное число. Отрицательные конечные наблюдения отмечаются отдельно, но не удаляются автоматически. Это не сертификат физической достоверности.

Годы извлекаются из имён файлов. Наличие 8760/8784 строк не доказывает корректность времени: временная зона, точные метки и их семантика не проверяются. Длины разрывов помечены steps (шаги индекса), а не часами. Перечень возможных временных полей и атрибутов сохранён для дальнейшего изучения.

## Результаты

После успешного чтения файлов появится:

```text
audit/
  report.md                    # Обзор и предупреждения
  summary.json                 # Полные параметры, схемы, проверки и ограничения
  pollutant_year_summary.csv   # Покрытие и численные показатели загрязнителей
  pm25_station_year.csv        # PM2.5: станции, годы и разрывы
  audit_results.zip            # Эти четыре небольших отчёта для передачи
```

Данные и модели в audit_results.zip не входят. Именно этот файл достаточно передать для обсуждения результатов; все исходные HDF5 пересылать необязательно.

Код возврата 0 означает завершённое сканирование без выявленных ошибок формата/масок в прочитанных HDF5. Это не означает подтверждение всех свойств данных: предупреждения и проверки метаданных всё равно нужно прочитать. Код 1 означает найденные ошибки/непрочитанные файлы; отчёт при этом всё равно записывается. Код 2 обычно означает неверные параметры запуска или ошибку загрузки.

## Ограничения для нашей статьи

1. Реальные времена доставки сообщений не восстанавливаются из годовых массивов. Задержки нужно моделировать и обозначать как искусственные.
2. Отсутствующее значение не доказывает отключение датчика: оно может отражать отсутствующий канал, фильтрацию, окончание работы станции и другие причины.
3. scaler.csv скачивается как исходный материал, но не применяется. Нормализацию нужно обучать только на обучающей части.
4. По предложенному протоколу 2021–2023 — обучение, 2024 — валидация, 2025 — тест. Не выбирайте станции и параметры модели по лучшим результатам или удобному покрытию 2025 года. Структурный аудит не равен подбору модели.
5. Тесты комплекта проверяют логику на синтетических массивах. Они не доказывают пригодность настоящего датасета.
