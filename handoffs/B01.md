## T02 — признаки и внутренний gate

`features/causal.py`: frozen fitted fallback только из train, sample identity по station/origin/target,
разделение по году target и расписание для каждой позиции, включая отсутствующую историю/target.
Лаги 1/2/3/6/12/24, mean/std 6/24 (ddof=0) по причинному forward-fill; station/global train median
до первой доступной истории. Quality block: шесть observed masks, age, missing ratios, current_gap,
has_history. Общий common block один; ID/календарь не превращаются в predictors.

Forecast строится до observe(target); TruthFrame существует отдельно, predict не принимает labels.
Сетка сохраняет разрывы и переходит через границу train/validation. Политика padding и age=-1
без истории явно зафиксирована до пилота в DECISIONS/B01_METHOD. Source validity не изменена.

Обязательные tests прошли до T03. Финальный gate: 11 passed, exit 0.
Проверены future/target invariance при frozen fit, hidden values, train-only fit без val/test reads,
границы годов, gap 100 шагов, отсутствие истории, identical common block и IDs,
неизменность выданных snapshots, 151 target / две станции / несколько ring wraps.
Это локальный gate B01, не внешнее APPROVED T02.

## T03 — модели, оценщик и артефакты

Реализованы Persistence, Standard, Quality-aware. Последние две — HistGradientBoostingRegressor
с одинаковыми hyperparameters, seed и train sample IDs; различие только в quality block.
Early stopping=false, validation_fraction=None. По результатам validation параметры не менялись.

Один wide prediction CSV на все scheduled validation targets. Оценщик присоединяет source truth
после predict, не заполняет отсутствующую истину и score на общем пересечении target IDs.
Сохраняет MAE/RMSE, macro station MAE, scheduled/predicted/scored, coverage и причины skips.
CLI: `train --config`, `evaluate --predictions --out`, `export-review --out`.
`prepare` остаётся T01 smoke; replay/benchmark не реализованы.

32 train-selected станции выбраны PCG64(seed=2026) из отсортированного списка 669 без возвращения;
выбранные ID отсортированы. `cohort.json` и `plan.json` записаны до labels/сравнения.
Model fit subset: target_index % 8 == 0, все выбранные станции; до fit сохранены sample IDs,
train matrices и fit_plan. Fallback fit использует весь доступный train выбранных станций.
Оба HGB обучены до первого numeric read validation; это защищено synthetic spy-тестом.

Внутренний reviewer-проход выполнен; замечания о literal zero времени Persistence и finite config
исправлены. Описание и ограничения reviewer evidence: `reports/B01/self_review.md`.
