## Что выполнено

**N1 — независимый expected plan.** `prediction_plan.py` и `evaluation.py` сверяют CSV
с заранее заданными station × target IDs и run/scenario/wait. Проверяются identity, год/local index,
origin, duplicates и clock metadata при наличии. Missing/extra/replaced IDs, даже с прежним count,
дают DataContractError до PASS. Missing prediction в существующей строке понижает coverage;
scoring по общему пересечению сохранён. Без явного plan или соседнего evaluation_plan.json оценка запрещена.
Train runner сохраняет новый plan до CSV. Replay повторно проверил старый B01 CSV с отдельно
восстановленным из его frozen metadata планом; исходные B01 artifacts не изменялись.

**T04 — общие seeded calendars.** `replay/calendars.py`: clean-source, random5/10/20%,
single/group blocks6/24, точные ID/интервалы/частота/длительность/seed/hash. Один календарь
на временной оси для всех методов/waits, не новый RNG для каждого overlapping window.
Natural missing, artificial drop и evaluator truth раздельны; уже отсутствующий input повторным
drop не считается. Group=ceil(.25×32)=8 станций, один блок в каждом bucket168steps;
это доля станций, не доля всех потерянных cells. Все фактические rates/denominators сохранены.
`replay/mixture.py` выдаёт weighted train-only FeatureFrame/TruthFrame samples; веса clean/random10/
group24/delay30 по .25, суммарный вес каждого исходного sample равен1. Real augmented fit: NOT_RUN.

**T05 — виртуальная доставка и ожидание.** `delivery.py`, `stream.py`, `cases.py`:
origin/interval_end/arrival/cutoff, монотонные часы, ties arrival<=cutoff, запрет незавершённых
и целевых интервалов, idempotent duplicates и ошибка при конфликте values, late updates
по event index без замены newer last-known, immutable issued snapshots.
Расписание forecasts работает и без сообщений. Waits0/5/15 сохраняют один target и remaining
lead60/55/45 simulated minutes до его конца. Никаких real sleeps.
Feature kernel общий с B01; модель не получает truth, scenario type или будущую доставку.
Truth присоединяется после predict. Реальное вычисление батчируется по immutable snapshots;
это offline simulation, не гарантия выдачи реальным сервисом точно в deadline.

**Интеграция.** `baseline.py` проверяет pinned B01 manifest/model/fallback/cohort/CSV hashes
и совместимость runtime до доверенной local model load; автоматического refit нет.
`runner.py` сохраняет plan до replay, проводит zero-control и expected-plan checks до PASS,
проверяет общие scored IDs и сохраняет output hashes. `replay --config` и новый `evaluate --plan`
реализованы и реально выполнены; export-review whitelist расширен для компактного B02 evidence.
Контракт: docs/B02_METHOD.md. Внутренняя самопроверка и исправления: reports/B02/self_review.md.
