# Пакет внешнего ревью B01

B01.md - итог APPROVED и одно неблокирующее замечание N1 для следующего блока.
CODEX_HANDOFF.txt - как перенести решение и сохранить ограничения следующего блока.
test_b01_review_checks.py - 14 дополнительных синтетических проверок, выполнены локально.
reproduce_coverage_gap.py - воспроизведение ограничения coverage на синтетическом CSV.
evidence/ - локальные логи, версии, проверки blob-хешей, арифметика и CI-наблюдения.

Исходные данные, обученные модели и реальные прогнозы не включены.
CI-summary - запись прочитанных логов GitHub, не новый запуск CI.
Локальные проверки не являются повтором полного проекта на его lock-зависимостях.
