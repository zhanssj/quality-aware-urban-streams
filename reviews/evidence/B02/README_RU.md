# Пакет ревью B02

Решение: APPROVED для назначенного блока. Отчёт B02.md и CODEX_HANDOFF.txt предназначены
для передачи агенту. Удалённый репозиторий этим пакетом не изменялся.

`test_b02_review_checks.py` - 28 независимых проверок; можно поместить в tests реального
проекта и выполнить установленным Python 3.14: `python -m pytest tests/test_b02_review_checks.py -q`.
Проектное форматирование/линт новых reviewer-тестов локально не проверялось.

`probe_fingerprint.py` показывает повторное хеширование на 80 шагах без временных замеров.
В реальном src-layout проекте используйте установленный editable package или PYTHONPATH=src.

`evidence/` содержит фактически полученный лог локальных проверок, хеши 7 исходных модулей,
сводку прочитанных CI логов, ограничения окружения и результаты небольшой репродукции N2.
Это не полные логи CI и не реальные HDF5/CSV/model artifacts.

`isolated_reproduction/` воспроизводит локальный проверочный стенд Python 3.13, а НЕ всё приложение.
Запуск: `python isolated_reproduction/run_isolated_checks.py`.
Там имеются помеченные import-only adapters для неиспользуемого HDF5/IO и адаптация аннотаций
при компиляции prediction_plan.py под Python3.13. Алгоритмические модули имеют исходные Git blob-хеши.
НЕ копировать этот core в рабочий src. В реальном Python3.14 проекте адаптация не требуется.

Реальные прогоны, модели и полный CSV прогнозов проверяющий не открывал и не повторял.
