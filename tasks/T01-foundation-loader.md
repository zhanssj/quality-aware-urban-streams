# T01: Основа проекта и загрузчик

Статус: READY_FOR_REVIEW. Code commit и evidence: handoffs/T01.md.

Предусловия: Нет. Это первая задача.

## Реализовать

Создать Python src-layout с пакетированием, CLI entry point, pytest и проверкой стиля. Использовать совместимый установленный Python; точные версии закрепить lock-файлом и документировать Windows/Linux запуск.
Read-only HDF5 reader для `values`, `masks`, `station_ids`, `params`: выбор PM2.5 по имени, выбор IDs, диапазона и chunk size. Проверять дубликаты IDs, формы и наличие нужных полей, не сканируя заново все значения за пять лет.
Строки временной сетки не удалять. `mask=0` или неконечные числа скрыть до выдачи потоку. Zero под mask=1 оставить.
Читать ограниченные блоки. Не хранить пять лет целиком в RAM. Использовать AQ_DATA_ROOT; отсутствие файлов - понятная ошибка с конкретным путём.
Задать configs smoke/baseline и локальную папку артефактов; пока не реализованные train/replay не должны сообщать об успехе.
Добавить CI на synthetic fixtures без оригинального датасета. Локальный test runner должен работать независимо от GitHub/GitLab.

## Тесты приёмки

1. Конечное число под mask=0 недоступно.
2. NaN/inf под mask=1 недоступны.
3. Валидный ноль остаётся нулём.
4. Выбор станции идёт по ID, а не предположению о позиции.
5. Пустые шаги не исчезают.
6. Chunked и цельное чтение маленького fixture совпадают.
7. Отсутствующие параметры/файлы и несовместимые формы дают понятную ошибку.
8. Reader не изменяет fixture (сравнить hash до/после).
9. Отсутствующий AQ_DATA_ROOT не вызывает скрытую сетевую загрузку.

## Реальный smoke-test

При доступном пути: прочитать только небольшой диапазон тренировочного 2023 года для 2–4 заданных IDs, не более 168 шагов. Сохранить размеры, количество доступных элементов и параметры чтения, без нового quality report всех лет.
Это проверка работы loader, не научный результат. Без локальных файлов - NOT_RUN.
