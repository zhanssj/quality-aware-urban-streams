# T03: Первое сравнение моделей и оценщик

Статус: TODO в назначенном B01.

Предусловия: T02 принят.
Для явно назначенного B01 это предусловие заменено успешными обязательными локальными тестами T02.
Это не внешнее APPROVED T02. Итоговый handoff и внешнее ревью — один раз в конце B01.

## Реализовать

Persistence + Standard + Quality-aware по протоколу. HistGradientBoostingRegressor с общими гиперпараметрами и без случайного внутреннего early stopping split.
Строить 32-station cohort детерминированно из приложенных 669 по тренировчному списку, сохранить выбор и seed. Не отбирать по val/test.
Synthetic smoke со всеми слоями; затем bounded real train/validation при доступных файлах.
Сохранить predictions, fit artifacts, run manifest, MAE/RMSE и coverage на одинаковых target. Для отсутствующей истины сохранять прогноз, но не score.
Добавить экспорт компактного review bundle по whitelist, без данных/секретов/моделей. Реальные крупные predictions остаются локально с hash/ref.
Пока единицы не проверены, пометить метрики диагностическими в units файла; не подписывать их физическими единицами.

## Тесты приёмки

На ручном fixture Persistence и ошибки совпадают с ручным расчётом; target не подменяется заполненным значением.
Повтор с одним seed/config воспроизводит результаты в заявленных численных допусках.
Все модели score на одинаковом target set; число skipped cases объяснено.
Artifacts содержат code/config/data/cohort provenance, а не выдуманные placeholders.
Test2025 command отвергается без gate. В логах этой задачи его открытие отсутствует.

## Итог

Первая таблица validation с реальными прогнозами либо готовая программа и честный NOT_RUN при отсутствии локальных данных.
Никакого обязательного улучшения Quality-aware.
