# T08: Необязательная потоковая интеграция

Статус: TODO / OPTIONAL

Предусловия: Исследовательское ядро принято; пользователь отдельно назначил расширение.

## Реализовать

Минимальный producer, Kafka, Python worker с уже существующим feature builder и сохранением predictions. Один согласованный event schema.
Эквивалентность offline replay и worker при том же arrival/cutoff расписании, явное поведение дубликатов/out-of-order.
Метаданные запусков в PostgreSQL и файлы в объектном хранилище только при реальной необходимости.
Spring control API отдельным небольшим изменением после worker, не второй реализацией ML/feature logic.
Docker Compose, healthchecks, конфигурация/секреты вне Git.

## Проверки

Offline/worker признаки и прогнозы совпадают в допусках; измеряется реальная end-to-end latency на указанном оборудовании.
Исследовательская matrix не переопределяется ради инфраструктуры. Нет HA, Kubernetes, UI и большого CI/CD проекта.
